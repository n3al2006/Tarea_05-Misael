# Tarea_05-Misael
Este es un repositorio para una tarea relacionado Git y Github.

El proyecto trada de crear un nuevo repositorio y dentro de él, crear un nueva
rama y crear un nuevo archivo junto con otro archivo **README**. El archivo que
se crea junto al **README** que en este caso yo le puse de nombre **juego.py**
también debe ser modificado.

**INFORMACION DEL CONTENIDO DE JUEGO.PY**
El contenido de ese archivo es un pequeño codigo sobre un juego clasico como
lo mencione anteriormente.

Primero lo que hice es importar la libreria random para hacer que la maquina
elija una opcion al azar (piedra, papel o tijera), estos estan alamcenados en un array.

En este juego, el while True: se usa para hacer que todo el juego ocurra dentro de un 
solo bloque repetible.

Aunque parece que el juego va a repetirse muchas veces, en realidad el juego solo se 
juega una vez, porque después de mostrar quién gana (jugador, máquina o empate), 
se usa break para salir del bucle.
